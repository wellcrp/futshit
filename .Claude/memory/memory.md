# Memória do projeto

## Regras obrigatórias
- Desenvolver somente o necessário: obrigatório.
- Aplicar boas práticas de desenvolvimento web: obrigatório.
- Priorizar segurança em toda a implementação: obrigatório.
- Garantir validação segura de formulários: obrigatório.
- Tratar dados sensíveis com cuidado, incluindo CPF e demais informações pessoais: obrigatório.
- Nunca expor chaves privadas ou segredos no front-end: obrigatório.
- Evitar dependências e plugins desnecessários: obrigatório.
- Realizar refatorações cirúrgicas sem introduzir bugs: obrigatório.

## Notas do projeto
- O projeto deve seguir um escopo web simples, limpo e seguro.
- Priorizar HTML5 semântico, acessibilidade e Bootstrap de forma adequada.
- Usar JavaScript com foco em clareza, manutenção e segurança.
- Informações sensíveis não devem ficar visíveis no front-end.
- Formulários devem validar entradas e oferecer feedback claro ao usuário.
