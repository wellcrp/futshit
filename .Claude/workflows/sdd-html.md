# Agent `sdd-html`

## Propósito
Verificar a padronização do HTML e orientar a codificação para aderir às melhores práticas de HTML5, SEO e acessibilidade.

## Comportamento esperado
- Analisar a estrutura HTML existente.
- Verificar elementos semânticos, uso correto de tags e hierarquia de títulos.
- Checar a presença de metadados importantes para SEO (`title`, `meta description`, `lang`, `viewport`).
- Avaliar imagens com `alt` e links com atributos adequados.
- Recomendar correções para melhorar o código e evitar práticas arriscadas.
- Garantir que a implementação continue consistente com o padrão do projeto.

## Uso
1. Executar `sdd-html` antes ou durante a implementação.
2. Validar o HTML atual e aplicar recomendações para melhores práticas.
