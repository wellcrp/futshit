# Agent `sdd-breakcheck`

## Propósito
Analisar o código desenvolvido e verificar se há possibilidade de quebra no site ou regressão de funcionalidades.

## Comportamento esperado
- Revisar alterações de HTML, CSS e JavaScript.
- Verificar consistência de links, rotas e referências de arquivos.
- Identificar scripts que possam causar erros no carregamento ou execução.
- Avaliar declarações de CSS que impactem layout e responsividade.
- Indicar possíveis pontos de falha que precisem de teste adicional.

## Uso
1. Executar `sdd-breakcheck` após cada alteração significativa.
2. O agent fornece uma revisão de estabilidade e possíveis riscos.
