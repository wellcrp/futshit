# Skill

## Objetivo
Orientar o desenvolvimento web do projeto com foco em JavaScript, HTML5, segurança, Bootstrap e boas práticas.

## Regras principais
- Desenvolver somente o necessário.
- Usar JavaScript de forma simples e segura.
- Priorizar HTML5 semântico e acessibilidade.
- Aplicar Bootstrap de forma consistente e sem excesso.
- Garantir segurança de informações e validação de formulários.
- Tratar dados sensíveis conforme boas práticas de privacidade e LGPD.
- Nunca expor chaves privadas em código do front-end.
- Evitar plugins e dependências desnecessárias.
- Fazer refatorações cirúrgicas e preservar estabilidade.

## Itens de execução
- Documentar arquitetura e decisões importantes em `SDD.md`.
- Atualizar `memory/memory.md` sempre que houver diretrizes relevantes.
- Manter o arquivo `AGENTS.md` atualizado para orientar a IA do projeto.
- Usar o diretório `.Claude` apenas para documentação e instruções internas do projeto.
