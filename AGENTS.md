# AGENTS.md

## Escopo do projeto
Este repositório é orientado para desenvolvimento web com foco em:
- JavaScript
- HTML5 semântico
- Segurança de aplicações web
- Bootstrap (última versão estável)

## Regras obrigatórias
- Sempre atualizar este arquivo antes de iniciar uma nova tarefa.
- Manter as instruções focadas no desenvolvimento web e no que for realmente necessário.
- Preferir soluções simples, legíveis e com baixo risco de quebra.
- Usar HTML5 semântico e acessibilidade sempre que possível.
- Preferir JavaScript simples e vanilla quando não houver necessidade de bibliotecas adicionais.
- Usar Bootstrap somente quando for útil e manter a implementação limpa.
- Garantir validação de formulários e tratamento seguro de entradas do usuário.
- Tratar dados sensíveis com cuidado, especialmente CPF e outros dados pessoais, alinhando-se à LGPD.
- Nunca expor chaves privadas ou segredos no front-end.
- Quando necessário, usar métodos seguros para proteger chaves de API e outras informações privadas.
- Realizar refatorações cirúrgicas, sem introduzir bugs ou alterações desnecessárias.

## Diretrizes de implementação
- Priorizar qualidade, segurança e manutenção.
- Evitar dependências desnecessárias.
- Manter o código organizado, claro e fácil de evoluir.
- Documentar mudanças importantes no contexto do projeto.
- Tarefa em andamento: incluir coluna de aproveitamento no ranking, calculando percentual de jogos participados sobre o total de partidas registradas.
